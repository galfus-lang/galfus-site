## What is Galfus?

Galfus is a highly modular interpreted scripting language. It's built around typed source code, an in-memory executable graph, and a deterministic VM runtime.

### Why deterministic?

Unlike traditional environments that rely on global garbage collectors, Galfus uses an ownership graph built on **Anchors** and **Edges**.

> "A language that respects memory is a language that respects the host."
> — The Galfus Team

## Code Example

Here is a quick look at a simple Galfus script:

```rust
// main.gfs
struct User {
    name: String,
    age: u8,
}

fn main() {
    let u = User {
        name: "Fusy",
        age: 1,
    };

    if u.age < 18 {
        println("Too young!");
    } else {
        println("Welcome, " + u.name);
    }
}
```
